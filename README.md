
# 🛋️ Sistema de Muebles Exclusivo Sofás

Sistema de gestión **SISTEMA ERP SOFAS**, orientado a la fabricación y comercialización de sofás.

## 📌 Descripción

Aplicación desarrollada en Java para facilitar la administración de los procesos de una empresa dedicada a la producción y venta de sofás.

## 🚀 Funcionalidades

- Gestión de clientes.
- Registro de productos y modelos de sofás.
- Control de inventario de materiales.
- Gestión de ventas.
- Registro de órdenes de producción.
- Administración de proveedores.
- Generación de reportes.

## 💻 Instalación

1. Instalar Java y las herramientas requeridas.
2. Clonar el repositorio:

```bash
git clone https://github.com/pedrodelgado-dev/Sistema-de-Muebles-Exclusivo-Sofas.git
```

3. Abrir el proyecto en IntelliJ IDEA.
4. Configurar las dependencias y la base de datos según corresponda.
5. Ejecutar la aplicación.
